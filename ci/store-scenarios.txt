# Brim App Store frames (docs/appstore/screenshots.md). Run by .github/workflows/store.yml:
#   P*  iPhone 6.9" and 6.1"/6.3" sets: ci/screenshots.sh (SCENARIOS=this file, SCENARIO_FILTER='^P[0-9]')
#   D*  iPhone Duo inner display: ci/duo.sh store pass (STORE_LIST=this file, STORE_FILTER='^D[0-9]'), which adds
#       `;orient=portrait` (tabletop canvas, 669 x 951 pt) and holds the hinge at 150 degrees
#   R*/DR*  reserves: not captured by default; run them with a filter like '^(P[0-9]|R[0-9])'.
# Then ci/store-set.sh frames each one under its caption (ci/store-frame.swift) and writes <set>/store/MANIFEST.txt.
#
# name|demo args (Brim/App/DemoMode.swift)|seconds to wait|caption: headline / sub-line|expect (optional extra regex)
#  - wait: a freezeOn scenario waits for the app's "BRIM-T freeze <x>" line instead (at least this long, max 60 s).
#  - caption: `*word*` is the ONE gold-swash word; " / " starts the sub-line. Seven words max per headline. No "|".
#  - checks (ci/store-set.sh, against logs/<name>.at-capture.txt): the "BRIM-T demo '…' starts" line, "BRIM-T freeze
#    <x>" for freezeOn=<x>, "BRIM-T streak seeded <n> (asked <n>)" for streak=<n>, the expect regex if given, and on
#    the Duo "BRIM-T orient portrait ok". A frame that fails one is written to store/_flagged/, never store/.
# Truthfulness: every caption must be true of the build (×5 = Rules.multiplier at streak 10; venues = 5 + a locked "?").
